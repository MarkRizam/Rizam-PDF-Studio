# Contributing to Rizam PDF Studio

Thanks for helping build a local-first open-source PDF editor.

## Before submitting a change
- Check existing issues and the roadmap.
- For substantial changes, open an issue describing your proposal.
- Work on a separate branch, and submit a pull request with a clear summary.
- Run `npm run check` and `npm run build` once the application source is present.
- Add tests when changing image geometry, PDF coordinate conversions, résumé parsing, or form mappings.

## Privacy and security
**Never upload real résumés, job applications, identity cards, signatures, salaries, passwords, or other sensitive documents to issues or pull requests.**
Use invented personal information and synthetic PDF fixtures only.
Report suspected vulnerabilities privately to the maintainers; see SECURITY.md.

## First contributions
Documentation improvements, cross-browser tests, accessibility, image cropping, and safer PDF form field matching are welcome. See ROADMAP.md.

By contributing, you agree to follow CODE_OF_CONDUCT.md. Contributions are submitted under the project's MIT license.
