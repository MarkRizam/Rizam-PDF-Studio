# Security policy

Rizam PDF Studio is an experimental local-first PDF editor. Do not rely on visual cover rectangles to securely redact confidential PDF content.

If you discover a security problem, **do not open a public issue containing exploit details or private documents**. Use GitHub's private vulnerability reporting feature if the repository has it enabled; otherwise contact the repository owner privately via their GitHub profile.

Do not include real resumes, national ID numbers, signatures, employer application forms, or other sensitive user information in a report. Sanitized reproduction steps and synthetic test files are preferred.

Maintainers will assess vulnerabilities and coordinate fixes without promising a specific response or disclosure deadline.
