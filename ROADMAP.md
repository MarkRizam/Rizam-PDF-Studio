# Roadmap

## Current prototype (v0.6)
- Local PDF viewing, annotating, image/signature insertion, crop and resize
- Manual PDF field placement
- Resume import from text-based PDF, DOCX and TXT with review
- Template-specific assistance for one four-page job application PDF
- PDF export

## Community priorities
- Generalized detection of PDF form fields and printed labels
- Reliable coordinate mapping and cross-browser PDF export tests
- Privacy-preserving OCR for scanned documents
- Better text editing, page reordering, undo/redo and keyboard accessibility
- Robust multilingual PDF fonts and form filling
- A secure redaction tool that actually removes underlying content

Please discuss significant features in an issue before coding.
